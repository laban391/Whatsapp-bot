LABAN-XMD — PXXL DEPLOYMENT

1. Upload/extract this ZIP so package.json and server.js are in the app root.
2. Select Node.js 20 or newer (Node.js 22 is also suitable).
3. Install dependencies with: npm install
4. Start command: npm start
5. Add these environment variables in PXXL (do not commit a real .env file):
   MONGO_URI=mongodb+srv://<db-user>:<new-password>@<cluster>/<database>?retryWrites=true&w=majority
   OWNER_NUMBER=254XXXXXXXXX
   BOT_OWNER=Laban
   PORT=3000 (or use the port assigned by PXXL)
   CHANNEL_LINK=
   YT_CHANNEL=LABAN-XMD
6. In MongoDB Atlas, allow network access from your hosting provider. Prefer a restricted
   provider IP range where available; avoid 0.0.0.0/0 unless the host requires it.
7. Deploy, then inspect the first startup log. MongoDB must connect before the HTTP server
   and saved WhatsApp sessions can start.

SECURITY: The original server.js contained a MongoDB URI with embedded credentials.
That fallback has been removed. If those credentials were real, rotate the database
password immediately and use the new URI only in PXXL environment variables.
